Editör, IDE & Terminal

Günün çoğunu içinde geçirdiğin araçlar: editörler, IDE’ler ve terminaller. Editör seçimi zevkten çok iş akışı meselesi; birini seçip kısayollarını gerçekten öğrenmek, sürekli değiştirmekten daha çok kazandırır.

22 bağlantı

Apache NetBeans

netbeans.apache.org

Java ağırlıklı, çok dilli açık kaynak geliştirme ortamı (IDE).

Açık Kaynak, Ücretsiz

Awesome CLI

github.com

Komut satırında kullanışlı, küçük araçları toplayan liste. awesome-shell gibi geniş listelerden farkı tek iş gören, hemen kurulup kullanılabilecek küçük araçlara odaklanması.

Awesome Liste, GitHub, CLI

Awesome Git Addons

github.com

git komut satırını genişleten ek komut ve araç listesi. Git istemcilerinden farkı grafik arayüz değil, `git`’e yeni alt komutlar ekleyen araçları toplaması.

Awesome Liste, GitHub, Git, CLI

Awesome Hyper

github.com

Web teknolojili terminal Hyper için tema ve eklenti listesi. Alacritty gibi yerel terminallerden farkı Electron üzerine kurulu olması: HTML/CSS/JS ile tema ve eklenti yazabiliyorsun; karşılığında daha ağır.

Awesome Liste, GitHub, CLI

Awesome Neovim

github.com

Neovim editörü için eklenti ve yapılandırma listesi. Vim eklenti listelerinden farkı Lua ile yazılmış ve Tree-sitter ile LSP gibi yalnız Neovim’de bulunan özelliklere dayanan eklentileri toplaması.

Awesome Liste, GitHub

Awesome VS Code

github.com

Visual Studio Code için uzantı ve kaynak listesi. Marketplace’in kendisinden farkı küratörlü olması: binlerce uzantı yerine denenmiş olanları dile ve işe göre gruplaması.

Awesome Liste, GitHub

Cmder

cmder.app

Windows için taşınabilir, güzel bir konsol paketi; bash ve unix komutlarıyla gelir. Yerleşik cmd’den farkı sekme, tema ve unix araçlarını bir arada sunması.

CLI, Açık Kaynak, Masaüstü

Eclipse Theia

theia-ide.org

Masaüstünde ve tarayıcıda çalışan, VS Code eklentileriyle uyumlu IDE çatısı. VS Code’dan farkı ürün değil çatı olması — kendi markanla, kendi eklenti setinle bir IDE inşa etmen için tasarlanmış.

Açık Kaynak, Masaüstü, Sunucu

Editor.md

pandao.github.io

Açık Kaynak, Tarayıcıda

Embarcadero Dev-C++

sourceforge.net

Ücretsiz, Masaüstü, C Ailesi, Ağ

Neovim

Vim’in yeniden yapılandırılmış hâli; yapılandırma ve eklentiler Lua ile yazılıyor, dil sunucusu (LSP) desteği yerleşik. Klasik Vim’den farkı bu Lua ekosistemi ve eşzamansız eklenti mimarisi.

Notepad++

notepad-plus-plus.org

Windows için hafif kaynak kodu editörü; sözdizimi renklendirme, çok dosyada arama-değiştir ve makro kaydı var. VS Code’a karşı tercih sebebi hız: dev bir günlük dosyasını saniyeler içinde açıyor, dil sunucusu beklemiyor.

Sublime Text

sublimetext.com

Hıza ve akıcılığa odaklı, çok hızlı açılan metin/kod editörü.

Visual Studio Code

code.visualstudio.com

Eklenti ekosistemiyle en yaygın kod editörü; hafif açılıyor ama dil sunucuları ve hata ayıklayıcılarla bir IDE’ye yaklaşıyor. JetBrains gibi tam IDE’lerden farkı her dili eklentiyle alman: temel küçük, yetenek eklentiden geliyor.

Açık Kaynak, Ücretsiz, Masaüstü

VSCodium

vscodium.com

VS Code’un Microsoft telemetrisi ve markası çıkarılmış topluluk derlemesi. Aynı editör, aynı eklenti API’si; farkı, varsayılan eklenti marketinin Microsoft’unki değil Open VSX olması — bazı kapalı eklentiler burada bulunmuyor.

Açık Kaynak, Masaüstü

WakaTime

wakatime.com

Editör eklentisiyle hangi projede, hangi dilde ne kadar zaman geçirdiğini ölçüyor. Genel zaman takip araçlarından farkı elle başlatma gerektirmemesi — ölçüm editörün kendisinden geliyor.

Gözlemlenebilirlik, Freemium, Eklenti

Warp

warp.dev

Rust ile yazılmış terminal; komutları ve çıktılarını metin akışı yerine ayrı "blok"lar hâlinde tutuyor, böylece bir komutun çıktısını tek tıkla kopyalayabiliyorsun. iTerm veya Windows Terminal’dan ayrıldığı yer bu blok modeli ve gömülü YZ komut önerisi.
