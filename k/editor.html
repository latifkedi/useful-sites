Editör, IDE & Terminal

Günün çoğunu içinde geçirdiğin araçlar: editörler, IDE’ler ve terminaller. Editör seçimi zevkten çok iş akışı meselesi; birini seçip kısayollarını gerçekten öğrenmek, sürekli değiştirmekten daha çok kazandırır.

25 bağlantı

1
Apache NetBeansnetbeans.apache.org

Java ağırlıklı, çok dilli açık kaynak geliştirme ortamı (IDE). IntelliJ IDEA’ya kıyasla tamamen ücretsiz ve Apache altında; karşılığında eklenti ekosistemi ve akıllı kod tamamlama tarafı daha zayıf.

Açık Kaynak · Ücretsiz · Masaüstü · JVM (Java, Kotlin, Scala)
2
Awesome CLIgithub.com

Komut satırında kullanışlı, küçük araçları toplayan liste. awesome-shell gibi geniş listelerden farkı tek iş gören, hemen kurulup kullanılabilecek küçük araçlara odaklanması.

Awesome Liste · GitHub · CLI
3
Awesome Git Addonsgithub.com

git komut satırını genişleten ek komut ve araç listesi. Git istemcilerinden farkı grafik arayüz değil, git’e yeni alt komutlar ekleyen araçları toplaması.

Awesome Liste · GitHub · Git · CLI
4
Awesome Hypergithub.com

Web teknolojili terminal Hyper için tema ve eklenti listesi. Alacritty gibi yerel terminallerden farkı Electron üzerine kurulu olması: HTML/CSS/JS ile tema ve eklenti yazabiliyorsun; karşılığında daha ağır.

Awesome Liste · GitHub · CLI

Awesome Liste · GitHub

Awesome VS Codegithub.com

Awesome Liste · GitHub

CLI · Açık Kaynak · Masaüstü
8
CodingFontcodingfont.com

İnteraktif · Ücretsiz

Açık Kaynak · Masaüstü · Sunucu

Açık Kaynak · Tarayıcıda · Ücretsiz

Ücretsiz · Masaüstü · C Ailesi · Ağ

CLI · Git · GitHub
