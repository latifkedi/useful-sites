C, C++ & Rust

In C and C++ the reference and good practice come from different places: the language itself from a reference like cppreference, how to write it from Stroustrup’s FAQs and conference talks. In Rust the official book is both the introduction and the shared vocabulary, and the compiler’s error messages are part of the teaching — which is why Rustlings moves you along faster than reading.
