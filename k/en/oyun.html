Game Development

Game development forks two ways: using a ready engine (Unity, Godot) or writing the engine itself. Most people want the first; awesome-godot and MagicTools give the tools, while Game Programming Patterns gives the game-specific code design.

12 links

Awesome Game Boy Dev

github.com

Game development for the Game Boy — assemblers, tools and hardware docs. Unlike modern engine lists it focuses on programming constrained retro hardware.

Awesome List, GitHub, Embedded

Awesome Game Development

github.com

A resource list covering every branch of game development from engines to asset tools. Unlike engine-specific lists it is engine-agnostic — a broad starting map.

Awesome List, GitHub, Reference

Awesome Game Engine Dev

github.com

Resources for writing the game engine itself, not a game — rendering, physics, ECS. Unlike engine-usage lists it aims at building an engine from scratch.

Awesome List, GitHub, Reference

Awesome Game Remakes

github.com

A list of actively maintained, open-source remakes of classic games. Unlike emulators the game’s engine has been rewritten from scratch — the code is readable.

Awesome List, GitHub, Open Source

Awesome Games of Coding

github.com

A list of games that teach a programming language by making games. Unlike dry exercises it ties learning to a game’s progression.

Awesome List, GitHub

Awesome Godot

github.com

A list of plugins, tutorials and example projects for the open-source Godot engine. Unlike the official docs it gathers the tools and templates the community produced.

Awesome List, GitHub, Open Source

Awesome Learn Gamedev

github.com

Course, book and community resources for learning to make games. Unlike tool lists it offers an ordered path and also covers side crafts like art, audio and design.

Awesome List, GitHub

Awesome Open Source Games

github.com

A list of playable games whose source is open. Unlike game stores these are projects whose code you can read to learn how they were made and build on.

Awesome List, GitHub, Open Source

CodinGame

codingame.com

A platform that has you solve programming puzzles with a game theme, showing your code’s result in a game scene. Unlike dry problem sets it animates your solution visually.

Free, Interactive

Game Programming Patterns

gameprogrammingpatterns.com

Robert Nystrom’s free book on the design patterns that recur in game code. Unlike general design-pattern books its examples are specific to the game loop and performance.

Book, Free, Tutorial

MagicTools

github.com

A list of tools and resources for game and graphics development — sprites, tiles, audio, level editors. Unlike engine lists it focuses on the helper tools in the production pipeline.

Awesome List, GitHub

Unity

unity.com

The most widely used cross-platform game engine; 2D/3D, mobile and console. Unlike Godot it has a huge asset store and industry ubiquity — most job listings ask for it.
