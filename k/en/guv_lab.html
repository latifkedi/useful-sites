CTF & Hands-on Labs

The labs split into those that hold your hand (TryHackMe) and those that do not (Hack The Box); moving to the second before you are ready usually wastes time. Run the deliberately vulnerable apps (Juice Shop, bWAPP) on your own machine, never exposed to the internet.

90 Days of Cyber Security

github.com

A study plan split across ninety days — networking, Linux, Python, then offence and defence. A dated schedule against the usual scattered resource list.

GitHub, Curriculum, Free

Awesome CTF

github.com

A list of tools, wargames and tutorials for Capture The Flag. Unlike a single contest it gives the whole toolchain needed to prepare, category by category.

Awesome List, GitHub, Security

bWAPP

itsecgames.com

A downloadable, deliberately vulnerable app containing 100+ web vulnerabilities. Unlike online targets it lets you practise on your own machine, isolated and without limits.

Security, Tutorial

Cicada 3301 Çözüm Rehberi

boxentriq.com

A step-by-step solution of the internet’s best-known puzzle, chaining steganography, book ciphers and Tor hidden services — a good example of how techniques link together.

Free, Security

CTF 101

ctf101.org

A ground-up guide to the categories in Capture the Flag competitions: reverse engineering, cryptography, forensics, web. Unlike a competition platform it hands you the fundamentals rather than challenges — the thing to read before your first CTF.

Security, Tutorial, Free

CTFtime

ctftime.org

A site scheduling Capture The Flag competitions worldwide and keeping team rankings. Unlike scattered announcements it gathers which contest is when in one place.

Security, Free

Damn Vulnerable iOS App

damnvulnerableiosapp.com

A deliberately vulnerable iOS app for learning mobile security.

Firing Range

public-firing-range.appspot.com

A Google-built test target hosting many application-security issues.

Security, Free

Gin & Juice Shop

ginandjuice.shop

A modern, vulnerability-filled web app practice target built by PortSwigger.

Security, Tutorial

Google CTF

github.com

Every challenge from Google’s CTF competitions, with source code and solutions. Unlike other archives the challenge infrastructure is published too, so you can stand the whole thing up locally and work through it.

Security, Open Source, GitHub

Google Gruyere

google-gruyere.appspot.com

Google’s “full of holes” codelab teaching web application flaws. Unlike pure theory it has you find each flaw and both exploit and patch it.

Security, Tutorial, Free

Hack The Box

hackthebox.com

Realistic machines with no hints — reconnaissance and research are entirely on you. That difficulty is why it turns up so often in OSCP preparation.

Freemium, Interactive, Security

Hack The Box Academy

academy.hackthebox.com

Module-based learning with practical certifications such as CPTS and CBBH. Against OSCP the learning path lives on the same platform as the exam and costs markedly less; in exchange, employer recognition is not yet at OSCP’s level.

Certification, Security, Interactive, Freemium

LabEx Cybersecurity Labs

labex.io

Hands-on, in-browser labs covering penetration testing and web security.

Security, Interactive, Tutorial

OverTheWire Wargames

overthewire.org

Classic wargames you play by SSH, advancing level by level. The Bandit series is the harshest and most durable way to learn the Linux command line.

Free, Security, Networking

OWASP Juice Shop

owasp.org

A modern web app deliberately full of vulnerabilities — a target for learning security. Unlike dry material it lets you exploit dozens of flaws by hand in a real application.

Security, Open Source, Tutorial

OWASP Vulnerable Web Apps Directory

owasp.org

OWASP’s directory of other deliberately vulnerable web apps for training.

Security, Reference, Awesome List

Trail of Bits CTF Field Guide

trailofbits.github.io

The CTF guide from the security firm Trail of Bits, laying out which skill each category needs and how to build it. Deeper than CTF101, and it bridges toward professional security work rather than stopping at the competition.

Security, Free, Book

TryHackMe

tryhackme.com

Guided labs that explain which tool you are using and why in each room. It holds your hand more than Hack The Box, which makes it the better first exposure to penetration testing.

Freemium, Interactive, Security

Web Security Academy

portswigger.net

PortSwigger’s free, hands-on web-security course — a live lab for each vulnerability. Unlike theory courses it has you perform the attack on a real target.

Security, Tutorial, Free, Interactive

Zodiac 340 Şifresinin Çözümü

blog.wolfram.com

A technical account of how a homophonic substitution cipher unsolved for fifty-one years was broken — a real worked example of hypothesis and elimination.

Free, Security, Tutorial

The category of ciphers still unbroken, the Voynich manuscript and Beale ciphers among them. Each stands as an open problem.

A list of solved and unsolved historical ciphertexts — real material for cryptanalysis practice instead of synthetic exercises.
