Data Engineering

Data engineering is about moving, transforming and making data reliable — the layer before analysis. Spark and Flink process, Kafka carries, dbt transforms, Airflow and Dagster orchestrate; on the warehouse side DuckDB and Iceberg set the new balance.

24 links

Airbyte

airbyte.com

Open-source data integration (ELT) with a huge connector catalogue; self-hostable.

Data Science, Open Source, Automation, Self-Hosted

Apache Flink

flink.apache.org

A real-time stream-processing engine that handles events as they arrive, with low latency. Unlike Spark’s batch roots it treats streaming as the first-class model.

Open Source, Automation

Apache Iceberg

iceberg.apache.org

An open table format for large analytical tables, giving schema evolution, time travel and atomic writes. Unlike a raw Parquet directory it manages the table as a consistent, versioned unit.

Open Source, Database

Apache Kafka

kafka.apache.org

Retains messages after consumption, with consumers carrying their own offsets so they can replay history. That durability is the real split from classic queues.

Open Source, Automation

Apache Spark

spark.apache.org

An engine that processes big data in a distributed, in-memory way — batch and streaming. Unlike single-machine libraries it splits terabytes across a cluster and processes them in parallel.

Open Source, Data Science, Automation
