Media, Design & Files

Most tools here do one thing well and are built to be chained. The browser-based ones never upload your file; the local ones handle batches — the first for one image, the second for a hundred. Open source is genuinely level with commercial software in this area, with colour-managed professional workflows the one exception.

42 links

3Dassets.one

3dassets.one

A search engine that consolidates several 3D asset sites into one query, filterable by licence and price. Against visiting each site, the licence filter is the point — you can isolate what is actually usable commercially.

Free, 3D

ambientCG

cc0textures.com

An archive of CC0-licensed PBR textures and materials, shipping colour, normal, roughness and displacement maps together. Unlike most texture sites the licence really is CC0 — no attribution needed, commercial use fine.

Free, 3D

Aseprite

aseprite.org

An editor built for pixel art and animation, with onion skinning, a frame timeline and sprite sheet export. Unlike a general painting program every tool snaps to the pixel grid, so anti-aliasing never appears where you did not ask for it.

Paid, Desktop, Interactive

AudioNotes

audionotes.app

Turns a voice note into structured text — summary, bullets, action items — rather than a raw transcript. For thinking aloud on the move and organising afterwards.

Paid, Freemium, Audio, Reference

Blender

blender.org

Modelling, texturing, rigging, simulation, rendering and video editing in one package. Against Maya or 3ds Max it is free, and it keeps the entire pipeline in a single program so nothing is lost in file handoffs.

Open Source, Free, 3D

Carbon

carbon.now.sh

Turns a snippet into a shareable image with theme, window chrome and line numbers under your control. Unlike a screenshot the result is reproducible and legible.

Free, Image Gen, System Design

CodingFont

codingfont.com

Compares coding fonts two at a time in a tournament until one wins. Unlike a font list it turns browsing into a decision — it never puts twenty fonts side by side, only two.

Interactive, Free

Coolors

coolors.co

A palette generator — hit space for a new combination, lock what you like and regenerate the rest. It checks contrast too.

Freemium, Image Gen

Devicons

vorillaz.github.io

An icon font of programming language and tool logos, used as technology badges in CVs, slides and READMEs.

Free, Image Gen

diagrams.net

app.diagrams.net

The online edition of draw.io, saving to Drive, OneDrive or local disk rather than keeping your file on its own server.

Free, Image Gen

draw.io

drawio.com

General-purpose diagramming with network, UML and AWS shape libraries. It saves to local disk or your own Drive and sends nothing to a server.

Open Source, Image Gen, Free

Excalidraw

excalidraw.com

A hand-drawn-style whiteboard. Looking deliberately rough is functional rather than stylistic — it stops a draft architecture being mistaken for a finished one.

Open Source, Image Gen, In Browser

Figma

figma.com

The de facto standard for interface design, whose multiplayer editing ended the desktop tools. Dev Mode hands measurements and tokens to developers.

Paid, Freemium, Image Gen

FontForge

fontforge.org

A font creation and editing program that converts between TTF, OTF and WOFF and lets you work on glyph hinting. Unlike an online font converter, you can get at the glyphs themselves.

Open Source, Free, Desktop

iLovePDF

ilovepdf.com

Merge, split, compress and convert with no installation. Be careful with sensitive documents — the file is uploaded to a server, and a local tool may be the better call.

Paid, Freemium, Reference

Inkscape

inkscape.org

A vector editor that uses SVG as its native format. Against Illustrator, the file is clean SVG ready for the web — no export step in between, and you can hand-edit the source.

Open Source, Free, Desktop

Krita

krita.org

A painting program for digital art and concept work, with a strong brush engine and frame-by-frame animation. Unlike GIMP it was built for drawing rather than photo editing, and brush latency and stabilisation are tuned accordingly.

Open Source, Free, Desktop

LosslessCut

github.com

Cuts and joins video without re-encoding, working on keyframe boundaries. Against a normal editor the operation takes seconds and loses no quality — trimming the head and tail off an hour of footage no longer means opening a timeline.

Open Source, Desktop, Video

LottieFiles

lottiefiles.com

An archive and editor of lightweight JSON-based vector animations, giving scalable motion at a fraction of a GIF’s file size.

Freemium, Image Gen

MediaInfo

mediaarea.net

Dumps the technical identity of a video or audio file: codec, bitrate, frame rate, colour space, container details. Unlike a player’s properties dialog it goes to stream level, which makes it the source of truth when something will not play.

Open Source, Free

Mermaid Live Editor

mermaid.live

Generates diagrams from text, so the source lives in version control with a readable diff. GitHub and GitLab render Mermaid natively.

Free, Image Gen, Reference

Moqups

moqups.com

Browser wireframing and prototyping. It lacks Figma’s design depth but is lighter and sufficient for a quick flow or screen sketch.

Paid, Freemium, Frontend

OpenReel Video

github.com

A video editor running in the browser with the footage staying on device — an alternative that needs no installation and no upload to a cloud service.

Open Source, GitHub, Video, In Browser

Photopea

photopea.com

An image editor in the browser that opens PSD, XCF, Sketch and XD files with their layers intact. Against GIMP it installs nothing and its PSD compatibility is genuinely good, which makes it the shortest path to opening a file someone sent you.

In Browser, Free

Piskel

piskelapp.com

A pixel art and sprite animation editor in the browser. Against Aseprite it is free and needs no install; in exchange the layer and brush tools are thinner — enough for your first sprite.

Open Source, In Browser, Free

Programming Fonts

programmingfonts.org

A place to try monospaced coding fonts side by side on real code. Unlike a font download site, you see the ligatures and the 0/O and 1/l/I distinctions in the context that actually matters.

Reference, Free, In Browser

ray.so

ray.so

Turns a snippet into a shareable image — a Carbon alternative with fewer knobs and a faster result.

Free, Image Gen

Same Energy

same.energy

Searches by visual similarity rather than keywords — you hand it an image and ask for more like it. Discovery through aesthetics, with no need to find the word first.

Free, RAG, Image Gen

SankeyDiagram.net

sankeydiagram.net

Generates Sankey flow diagrams from text input, for energy, budget or funnel flows. Unlike general diagram tools it does one chart type, and takes its input as text rather than as drawing.

Open Source, In Browser, Free

ShareX

getsharex.com

A screenshot and recording tool for Windows that chains post-capture steps: upload, shorten, OCR. What separates it from Snipping Tool is that workflow automation — capture and link-on-clipboard becomes one shortcut.

Open Source, Free, Desktop

Shutter Encoder

shutterencoder.com

A converter wrapping FFmpeg with a UI, offering the intermediate codecs and batch jobs editors need. Against HandBrake it is aimed at post-production — ProRes, DNxHD and subtitle burn-in sit in the menu rather than in a command line.

Open Source, Free, Video

Squoosh

squoosh.app

Image compression with a side-by-side comparison, running MozJPEG, WebP and AVIF encoders in the browser through WebAssembly. Unlike TinyPNG nothing is uploaded, and every encoder setting is yours to tune.

Open Source, In Browser, Free

Subtitle Edit

github.com

A subtitle editor that shows a waveform and spectrogram underneath, reads over 200 formats, shifts timings and extracts burned-in subtitles by OCR. Those synchronisation tools are what separate it from simple subtitle editors.

Open Source, Desktop, Free

Subtitle Editor Online

subtitle-editor.org

A subtitle editor in the browser for opening .srt and .vtt files and fixing timings and text. Against desktop tools like Subtitle Edit it installs nothing, which is what you want for a quick fix on someone else’s machine.

In Browser, Free

SVG Path Editor

yqnn.github.io

Edits SVG path data (the `d` attribute) visually while listing the commands one by one. Against a general vector editor you get at the raw path text, which is what you want for fixing a hand-written icon.

Open Source, In Browser, Frontend, Free

The Noun Project

thenounproject.com

A searchable archive of millions of icons and symbols, with several visual takes on each concept. Unlike an icon library it is not a consistent set but a dictionary of concepts — the place where an icon for one very specific object actually exists.

Freemium, Free

TinyPNG

tinypng.com

Shrinks PNG and JPEG files through selective quantisation: drag, drop, no settings. Against Squoosh it offers batch processing and an API — Squoosh for one image, this for a hundred.

Free, In Browser

UI Design Daily

uidesigndaily.com

Free UI component designs published daily, with the source files open and downloadable in Figma and Sketch format.

Free, Image Gen

Vector Magic

vectormagic.com

Converts a bitmap image into vector art. Against Illustrator’s trace, its edge detection is noticeably cleaner — it is the best route to recovering a logo from a low-resolution PNG.

Paid, In Browser

VS Code Themes

vscodethemes.com

A gallery previewing VS Code themes on real code. Against the marketplace you see a theme without installing it, and can compare how it looks across several languages at once.

Reference, Free, In Browser

XnConvert

xnview.com

Batch image conversion and processing that reads over 500 formats and writes around 70, with resize and watermark steps chained together. Unlike online converters it handles thousands of files locally with no size cap.

Free, Desktop

YouTube Video Kesici

appsgolem.com

Cuts and downloads a specific range from a video — faster and kinder to disk than downloading the whole thing and trimming.

Free, Video, Reference
