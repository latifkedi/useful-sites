AI · Models & Assistants

Three separate decisions: which model, where it runs, and where the data goes. Closed APIs give the best performance but your prompt leaves your machine; open-weight models run on your own hardware at the cost of setup and VRAM.

Claude model versions, context limits and token pricing. Unlike the chat app it takes the developer’s view, laying out cost-reducing features such as prompt caching and the batch API side by side.

Artificial Analysis

artificialanalysis.ai

Independent charts comparing LLMs by speed, price and quality.

Awesome ChatGPT

github.com

A list of tools, plugins and resources for ChatGPT, OpenAI’s chat model. Unlike general LLM lists, it gathers only apps, browser extensions and clients built around ChatGPT.

Awesome List, GitHub, LLM

Can I Vibecode It?

canivibecodeit.com

A table testing whether AI can rebuild a thousand-odd apps, with the verdict published. Unlike abstract benchmarks it targets real apps and hands you the exact prompt used, so the result is reproducible.

Free, Reference, Observability

ChatGPT

chatgpt.com

Sandboxed Python execution, image generation, file upload and custom GPTs in one window. The breadth costs it depth — no single capability is best-in-class.

Paid, Freemium, LLM

Claude

claude.ai

Anthropic’s chat app, whose long context window carries long documents and whole codebases. Compared with its rivals it stands out for consistency over long text; Projects keeps files as persistent context across chats, and Artifacts runs output in a side panel.

Paid, Freemium, LLM

Cohere

cohere.com

Rather than compete on chat, it sits on the retrieval side: its Rerank model reorders candidates returned by vector search and visibly lifts RAG precision.

API, Paid, Embedding

DeepSeek

deepseek.com

V3 and R1 weights are downloadable. Unlike closed models it is open, and its mixture-of-experts architecture keeps total parameters high while activating only a slice per token — reasoning performance at far lower inference cost.

Open Weights, LLM

Google AI for Developers

ai.google.dev

Developer gateway for the Gemini API and the open-weight Gemma family. Compared with the OpenAI API, its free tier is wide enough to carry a real prototype and asks for no card.

API, Docs, LLM

Google AI Studio

aistudio.google.com

A browser surface for testing prompts, setting system instructions and fiddling with temperature. Instead of writing API code first you try things here, then export the call you like as ready code.

In Browser, Free, API, Interactive

Google Gemini

gemini.google.com

Google’s chat assistant, connecting straight into Gmail, Drive and YouTube to use your own content as source. Unlike ChatGPT it has that integration — decisive if you live in Google’s ecosystem, irrelevant if you do not.

Paid, Freemium, LLM

Groq

groq.com

An LLM inference service delivering very high tokens per second on its own LPU hardware. Unlike GPU-based providers it runs on that custom chip — open models at unusual speed, with a limited model selection.

LLM, API, Freemium

Hugging Bay

huggingbay.xyz

An alternative browser placing open models side by side with licence and provenance. It publishes SHA-256 hashes for downloads, so integrity is verifiable.

Free, Open Weights, Open Source

Hugging Face

huggingface.co

The central repository for models, datasets and Spaces demos. Unlike general code hosts, every model card carries licence, training data and eval results in a standard form — read it before you download.

Free, Open Weights, Data Science, Awesome List

Jan

jan.ai

A desktop app that runs models locally and offline. Unlike LM Studio it is fully open source; chat data never leaves the device.

LLM, Open Source, Open Weights

Kimi Claw

kimi-claw.com

A hosted layer on OpenClaw adding persistent memory, scheduled tasks and jobs that fire without being asked. For people who want it as a ready service rather than operating OpenClaw on their own machine.

Paid, Freemium, Agent

Kimi K2.7 Code

huggingface.co

Moonshot AI’s code-focused open-weight model. Compared with closed coding models its weights are open — a genuine option if you want a local coding assistant without wiring yourself to a closed API.

Open Weights, System Design

LM Studio

lmstudio.ai

A desktop app for finding GGUF models, downloading them and picking a quantisation level. Unlike Ollama it tells you upfront which quant fits your RAM; there you work that out yourself.

Desktop, Free, Self-Hosted

LMArena (Chatbot Arena)

lmarena.ai

An arena ranking LLMs on an Elo leaderboard from human votes in blind battles. Unlike automated benchmarks it rests on real user preference; in exchange, style and answer length can skew the ranking.

LLM, Reference, Free

LocateAnything-3B

huggingface.co

A visual grounding model that boxes an object in an image from a text description. Unlike classification it is not tied to a predefined label set.

Open Weights, LLM

Meta Llama

llama.com

Weights are downloadable and run on your own hardware. The licence is not fully OSI-compliant: there is a monthly-active-user threshold for large commercial use — read it before shipping.

Open Weights, LLM, Self-Hosted

Microsoft Copilot

copilot.microsoft.com

Runs embedded in Word, Excel and the Windows shell, so you operate on a document without copying it to a website. Unlike ChatGPT the difference is the delivery point rather than the model — the models underneath are OpenAI’s.

Paid, Free, LLM

Mistral AI

mistral.ai

A Europe-based model provider. Compared with US providers it operates under EU data rules, and ships small models under Apache-2.0 that fit on a single consumer GPU.

Open Weights, LLM, Freemium

NotebookLM

notebooklm.google.com

Builds a context limited to the PDFs, docs and links you upload, and refuses to answer outside them. Unlike general chatbots it has that constraint — it cuts hallucination, at the price of not answering general questions.

Paid, Free, RAG, Academic

Ollama

ollama.com

Built on llama.cpp; one command pulls and runs a model. Unlike using llama.cpp directly, it exposes an OpenAI-compatible local endpoint, so existing client code runs unchanged.

Open Source, CLI, Self-Hosted

Open WebUI

openwebui.com

A web front-end for Ollama or any OpenAI-compatible endpoint, usually deployed with Docker. Instead of chatting on the command line, it adds multi-user accounts, role management and document upload for RAG.

Open Source, Self-Hosted, Docker, In Browser

OpenAI API Dokümantasyonu

developers.openai.com

Parameter reference for the Chat Completions, Responses and Realtime endpoints. Unlike community guides it is the primary source — the last word on function-calling schemas and streaming behaviour.

Docs, API

OpenAI Platform

platform.openai.com

API keys, rate limits and billing, with organisation-level quota settings and usage graphs. Unlike a ChatGPT subscription, API usage is billed separately, per token.

API, Paid, LLM

OpenClaw

openclaw.ai

A personal assistant that runs on your own machine; it has no UI of its own and hooks into chat apps you already use, such as WhatsApp and Telegram. Unlike hosted assistants, data never leaves the device.

Open Source, Self-Hosted, LLM, Agent

OpenRouter

openrouter.ai

One endpoint reaching many LLMs, routing by price and availability across providers. Instead of an account with each provider, one key and one bill.

LLM, API, Freemium

Perplexity

perplexity.ai

Turns your query into a web search, feeds the retrieved pages to a model, then footnotes each sentence. It is a RAG pipeline: answers rest on live search results, not the model’s memory.

Paid, Freemium, RAG

Replicate

replicate.com

Lets you run open machine-learning models through a single API. Unlike renting your own GPU it bills per second — you pay only for run time, with nothing to set up.

LLM, API, Freemium

Together AI

together.ai

Serves open-weight large language models with fast hosted inference. Unlike routers such as OpenRouter, it runs models on its own infrastructure and offers fine-tuning too.

LLM, Open Weights, API, Freemium

Unlimited-OCR

huggingface.co

Baidu’s OCR model, extracting text from long multi-column documents with no page ceiling. Markedly better than a classic Tesseract pipeline at preserving tables and layout.

Open Weights, Reference

vLLM

docs.vllm.ai

An inference engine that pages the KV cache with PagedAttention to use GPU memory efficiently. Compared with Ollama, continuous batching pushes concurrent-request throughput far higher — built for serving, not a single user.
