Online Playgrounds & Compilers

For running code without installing anything: browser playgrounds, online compilers and shareable IDEs. The fastest way to show someone a bug is to reproduce it here in a small example. Do not paste secrets or company code — most are public by default.

21 links

.NET Fiddle

dotnetfiddle.net

Write, run and share C# and .NET code in the browser — no install.

In Browser, Free

CodePen

codepen.io

A browser playground for HTML, CSS and JavaScript. The real value is discovery — you learn by taking apart other people’s CSS tricks.

Freemium, In Browser, Frontend

CoderPad

coderpad.io

A collaborative editor for running technical interviews with live coding (many languages).

Interview, Freemium

CodeSandbox

codesandbox.io

Runs projects with full npm dependencies in the browser. Unlike CodePen it opens a real React or Node project as-is.

Freemium, In Browser

CodeShare

codeshare.io

Real-time collaborative code editing in the browser with no install or account — a fast option for remote pairing or an interview.

Free, In Browser

Compiler Explorer

godbolt.org

Puts the generated assembly beside your source, with optimisation level and compiler version switchable so you see the difference immediately. It moves performance arguments from opinion to measurement.

Open Source, C Family

ES6 Console

es6console.com

A console that compiles modern JavaScript (ES6+) in the browser and shows the result instantly.

JavaScript, In Browser, Free

Ideone

ideone.com

Compiles and runs 60+ languages in the browser and accepts an input stream — for trying a language’s syntax without installing anything.

Free, In Browser

JS Bin

jsbin.com

A JSFiddle-like scratchpad with a live output panel; showing console output on the same screen is handy when debugging.

Free, In Browser, JavaScript

JSFiddle

jsfiddle.net

The oldest and lightest way to test a small JavaScript snippet — the standard tool for attaching a reproducible example to a bug report.

Free, In Browser, JavaScript

Judge0 IDE

ide.judge0.com

An open-source online compiler whose engine you can self-host — the project people building code assessment systems use as infrastructure.

Open Source, In Browser

Liveweave

liveweave.com

An in-browser playground to try HTML, CSS and JS with live preview.

Frontend, In Browser, Free

myCompiler

mycompiler.io

An online IDE supporting many languages, with no install.

In Browser, Free

Ona (eski Gitpod)

ona.com

Starting as the Gitpod cloud dev environment, it became Ona in 2025 — a platform for background AI coding agents.

Freemium, Agent

OneLang

onelang.io

An experimental tool that converts code written in one language into others — C#, Java, Python, JavaScript. Against a syntax comparison table it produces working translations, which shows how one language’s idiom lands in another.

Open Source, In Browser, Free

OnlineGDB

onlinegdb.com

An online IDE that compiles and debugs C and many languages in the browser (gdb included).

In Browser, Free, C Family

PlayCode

playcode.io

A JavaScript and TypeScript playground that runs as you type and accepts npm packages. Against CodePen the feedback is instant and the console always visible; against CodeSandbox it is lighter for trying a library.

In Browser, JavaScript, Freemium

Replit

replit.com

A collaborative cloud IDE that writes and runs dozens of languages in the browser.

In Browser, Freemium

RunJS

runjs.app

A JavaScript playground that evaluates as you type, showing a variable’s value without a `console.log`.

Freemium, JavaScript

StackBlitz

stackblitz.com

Runs Node.js in the browser through WebContainers, so install and restart are instant with no server round trip — it even works offline.

Freemium, In Browser

Wandbox

wandbox.org

Runs dozens of C++ compiler versions side by side — for testing which standard or compiler release a behaviour comes from.

Free, In Browser, C Family
