Online Playgrounds & Compilers

For running code without installing anything: browser playgrounds, online compilers and shareable IDEs. The fastest way to show someone a bug is to reproduce it here in a small example. Do not paste secrets or company code — most are public by default.

21 links

1
.NET Fiddledotnetfiddle.net

Write, run and share C# and .NET code in the browser. Instead of installing Visual Studio you try a small snippet at once — the .NET counterpart to JSFiddle.

In Browser · Free
2
CodePencodepen.io

A browser playground for HTML, CSS and JavaScript. Unlike JSFiddle its real value is discovery — you learn by taking apart other people’s CSS tricks.

Freemium · In Browser · Frontend
3
CoderPadcoderpad.io

A collaborative editor for technical interviews with live coding (many languages). Unlike simple shared editors such as CodeShare, it runs the code and can replay the session step by step afterwards.

Interview · Freemium
4
CodeSandboxcodesandbox.io

Runs projects with full npm dependencies in the browser. Unlike CodePen it opens a real React or Node project as-is.

Freemium · In Browser
5
CodeSharecodeshare.io

Real-time collaborative code editing in the browser with no install or account. Compared with CoderPad it does not run code, but it opens instantly — a fast option for remote pairing or an interview.

Free · In Browser
6
Compiler Explorergodbolt.org

Puts the generated assembly beside your source, with optimisation level and compiler version switchable so you see the difference immediately. It moves performance arguments from opinion to measurement.

Open Source · C Family
7
ES6 Consolees6console.com

A console that compiles modern JavaScript (ES6+) in the browser and shows the result instantly. Unlike the browser console, it also shows side by side how your code transpiles to older JavaScript.

JavaScript · In Browser · Free
8
Ideoneideone.com

Compiles and runs 60+ languages in the browser and accepts an input stream. Unlike project environments such as Replit it is light, for single files — trying a language’s syntax without installing anything.

Free · In Browser
9
JS Binjsbin.com

A JSFiddle-like scratchpad with a live output panel; showing console output on the same screen is handy when debugging.

Free · In Browser · JavaScript
10
JSFiddlejsfiddle.net

The oldest and lightest way to test a small JavaScript snippet. Unlike CodePen it is about reproducible examples rather than discovery — the standard tool for attaching one to a bug report.

Free · In Browser · JavaScript
11
Judge0 IDEide.judge0.com

An open-source online compiler. Unlike closed services such as Ideone you can self-host its engine — the project people building code assessment systems use as infrastructure.

Open Source · In Browser
12
Liveweaveliveweave.com

An in-browser playground to try HTML, CSS and JS with live preview. Unlike CodePen it is a plain, account-free scratchpad without the community and discovery layer.

Frontend · In Browser · Free
13
myCompilermycompiler.io

An online IDE supporting many languages, with no install. Unlike Replit you can run and share single-file code by link without an account; the trade-off is limited multi-file project support.

In Browser · Free
14
Ona (eski Gitpod)ona.com

Starting as the Gitpod cloud dev environment, it became Ona in 2025 — a platform for background AI coding agents. Unlike cloud environments such as GitHub Codespaces, it now centres on the agents running inside rather than the environment itself.

Freemium · Agent
15
OneLangonelang.io

An experimental tool that converts code written in one language into others — C#, Java, Python, JavaScript. Against a syntax comparison table it produces working translations, which shows how one language’s idiom lands in another.

Open Source · In Browser · Free
16
OnlineGDBonlinegdb.com

An online IDE that compiles C and many other languages in the browser. Unlike run-only sites such as Ideone it includes the gdb debugger, so you can set breakpoints and step through.

In Browser · Free · C Family
17
PlayCodeplaycode.io

A JavaScript and TypeScript playground that runs as you type and accepts npm packages. Against CodePen the feedback is instant and the console always visible; against CodeSandbox it is lighter for trying a library.

In Browser · JavaScript · Freemium
18
Replitreplit.com

A collaborative cloud IDE that writes and runs dozens of languages in the browser and can deploy a project in one click. Unlike snippet playgrounds such as JSFiddle, it runs whole projects with a filesystem, package installs and hosting.

In Browser · Freemium
19
RunJSrunjs.app

A JavaScript playground that evaluates as you type. Unlike the browser console it shows each line’s value alongside without a console.log.

Freemium · JavaScript
20
StackBlitzstackblitz.com

Runs Node.js in the browser through WebContainers. Unlike online IDEs that spin up server-side containers, install and restart are instant — it even works offline.

Freemium · In Browser
21
Wandboxwandbox.org

Runs dozens of C++ compiler versions side by side. Unlike Compiler Explorer it shows the program’s run output rather than the assembly — for testing which standard or compiler release a behaviour comes from.

Free · In Browser · C Family
