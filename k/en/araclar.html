Productivity & Everyday Tools

Project and note tools, sharing, operating-system helpers and browser extensions. Most things here have dozens of alternatives; a good rule is to bookmark the ones needing no installation and install the rest only when the need is real.

23 links

AppList

sxp.studio

A text-list app launcher for iPhone. Unlike the default icon grid it removes attention-grabbing colourful icons — deliberate friction on the digital minimalism side.

Free, Reference

Asana

asana.com

A project-management platform tracking team work, tasks and workflows. Compared with Jira it suits non-software teams better and is lighter to set up, with fewer development-specific features.

Freemium

Awesome Calculators

github.com

A list of calculator tools for every platform. Unlike a single calculator, it arranges options by platform — desktop, mobile, web, command line.

Awesome List, GitHub

Awesome No-Login Web Apps

github.com

A list of useful web apps that work without login. Unlike general tool lists, it picks only those with no sign-up — use them at once without handing over data.

Awesome List, GitHub, Free

Awesome Userscripts

github.com

A list of userscripts that enhance your browsing experience. Unlike browser extensions, they are small scripts with readable source that run under a manager such as Tampermonkey.

Awesome List, GitHub, In Browser, Plugin

Everything

voidtools.com

Instant filename search on Windows, built by reading the NTFS master file table directly. That is the trick against Windows Search: it does not index content, so the first scan takes seconds and results appear as you type.

Free, Desktop

Full Page Screen Capture

chrome.google.com

A Chrome extension that captures an entire page — scrolling included — as one image. Compared with DevTools’ hidden full-size screenshot command it is one click, and can save as PDF too.

Plugin, Free

GitHub Gist

gist.github.com

Shares single-file snippets with version history; comments and forking make it more durable than a pastebin.

Free, GitHub

Google Keep

keep.google.com

A quick sticky-note tool synced in the cloud, with lists, reminders and voice notes. Unlike Notion or Obsidian it wins on speed — you jot without building structure; the trade-off is limited formatting and linking.

Free

Image Max URL

qsniyg.github.io

A browser extension that finds the largest/original version of an image or video from its shrunken form. Unlike right-click “open image” it reverses the resizing: it resolves the full-resolution source from a thumbnail URL.

In Browser, Plugin, Open Source

Jira

atlassian.com

Agile project management with strong issue and release tracking for software teams. Compared with Trello it is heavy with a longer learning curve, but built for large teams that need sprints, workflows and reporting.

Freemium

MacroDroid

macrodroid.com

Builds trigger-action rules on Android — Wi-Fi on when you reach a location, silent while charging. Less powerful than Tasker and vastly more comprehensible.

Freemium, Automation

Microsoft PowerToys

learn.microsoft.com

The official set of tools that adds what Windows lacks: window layouts (FancyZones), bulk rename, colour picker, text extraction. Unlike third-party equivalents it is built and kept open source by Microsoft, so updates do not break it.

Open Source, Free, Desktop

Notion

notion.so

A tool combining notes, wikis, databases and project boards in one workspace. Unlike Obsidian it is cloud-based and team-oriented; in exchange your data is not local files and offline use is limited.

Freemium

Pastebin

pastebin.com

The simplest way to share text or a log, with syntax highlighting and expiry. Unlike GitHub Gist it needs no account; remember not to paste anything sensitive.

Free

ProtectedText

protectedtext.com

An encrypted online notepad that needs no registration; the password never leaves your browser. Unlike Pastebin, the server never sees the note in plain text.

Privacy, Free

Rufus

rufus.ie

A Windows tool for writing bootable USB drives that works out the UEFI/BIOS and partitioning details itself. What sets it apart from other writers is the option to strip the TPM and account requirements out of a Windows 11 install.

Open Source, Free, Desktop

Siteyi Çevrimdışı İndirme

dynomapper.com

A guide comparing methods for archiving a site offline — wget, HTTrack and the rest. Unlike a single tool’s docs it sets the methods side by side; practical preparation for documentation at risk of vanishing.

Free, Tutorial, Reference

Slack

slack.com

A team-communication platform organised by channels, with tool integrations. Compared with Discord it is work-oriented with a strong integration ecosystem; the free plan limits message history to 90 days.

Freemium

Snapdrop

snapdrop.net

Browser-to-browser file transfer between devices on the same network, connected directly over WebRTC. Unlike AirDrop it does not care about the operating system — Android to Mac works — and needs no install or account.

Open Source, In Browser, Free

Todoist

todoist.com

A to-do tool for personal and team projects, focused on fast capture. Unlike all-purpose tools such as Notion it focuses solely on tasks, and understands natural-language dates like “tomorrow at 9”.

Freemium

Trello

trello.com

A simple task tool managing projects with cards and boards (Kanban), owned by Atlassian. Compared with Jira it takes minutes to set up, but does not meet large teams’ reporting needs.

Freemium

Udeler GUI

github.com

Downloads Udemy courses you own for offline viewing; the repository was archived in 2024. Unlike the Udemy app’s offline mode the files stay with you — though it may no longer work on Udemy’s DRM-protected courses.

Open Source, GitHub, Reference, Archived
