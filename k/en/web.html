Web & Frontend

Browser compatibility sits behind every decision, which is why MDN’s support tables matter more than tutorials. When choosing tools, start from the need: for most content sites a static site generator (Hugo, Docusaurus) is less work than a single-page app framework. CSS and UI kits have their own heading.
