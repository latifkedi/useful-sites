Open Access & Archives

Legal open access and preservation: public-domain books, openly licensed textbooks, peer-reviewed open journals and the archives that keep the web itself. When a paper sits behind a paywall, try Unpaywall first — most work has a legal copy its author uploaded.

16 links

1
archive.todayarchive.today

An archiver that freezes a page exactly as it is and produces a permanent snapshot. Unlike the Wayback Machine it snapshots on demand, instantly and without heeding robots.txt, and keeps a screenshot of the page too.

Reference · Archived · Free
2
Awesome Web Archivinggithub.com

A list of tools and resources for preserving the web for the future (archiving). Unlike using the Wayback Machine, it gathers tools for running your own archive — crawlers, WARC tools, replay; maintained by the IIPC consortium.

Awesome List · GitHub · Reference · Archived
3
COREcore.ac.uk

The largest aggregator gathering the world’s open-access research papers in one place. Unlike Google Scholar it focuses only on open-access texts and harvests the full texts, serving them through an API.

Academic · Reference · Open Source · Free
4
DOAB — Directory of Open Access Booksdoabooks.org

A directory of peer-reviewed open-access academic books, linking out to publishers or repositories such as OAPEN. Unlike general e-book archives, it lists only publisher-approved books that have passed peer review.

Academic · Book · Open Source · Free
5
DOAJ — Directory of Open Access Journalsdoaj.org

A vetted directory of peer-reviewed open-access journals — legal and free. Unlike general academic search it lists only journals verified as non-predatory: a filter that screens journal quality up front.

Academic · Reference · Open Source · Free
6
grab-sitegithub.com

An archivist’s web crawler with WARC output and a dashboard for all crawls. Unlike tools like wget it has dynamic ignore rules: you exclude trap patterns mid-crawl, so large sites archive cleanly.

Archived · GitHub · Python · CLI
7
Internet Archivearchive.org

A vast digital archive preserving the web, books, audio and video — home of the Wayback Machine. Unlike archive.today it goes beyond web pages, with book lending and software and media collections.

Reference · Archived · Free
8
LibreTextslibretexts.org

A free platform compiling university-level open textbooks subject by subject. Unlike printed textbooks they are online, adaptable and carry embedded interactive elements.

Academic · Book · Open Source · Free
9
ManyBooksmanybooks.net

A library offering public-domain and indie-author ebooks free in many formats (EPUB, PDF, Kindle). Unlike Project Gutenberg it also carries contemporary indie-author books, with a more reader-friendly interface.

Book · Free · Reference
10
Online Library of Libertyoll.libertyfund.org

Liberty Fund's open library offering classic works on liberty, economics and political philosophy (Locke, Smith, Mill…) for free. Unlike shadow libraries everything here is public-domain or openly licensed and carefully typeset.

Book · Reference · Academic · Free
11
Open Libraryopenlibrary.org

Internet Archive’s open catalogue aiming for a page per book, lending many of them. Unlike bibliographic-only catalogues it lets you read scanned books through time-limited digital lending.

Book · Reference · Open Source · Free
12
Perma.ccperma.cc

Creates permanent archived copies of cited links to stop link rot; library-backed. Unlike general archivers it is aimed at academic and legal citations, with permanence underwritten by libraries.

Reference · Archived · Free
13
Project Gutenberggutenberg.org

The oldest digital library, offering more than 70,000 public-domain classics free. Unlike Standard Ebooks it wins on scale; the trade-off is that typesetting and formatting quality varies from book to book.

Book · Open Source · Free
14
Standard Ebooksstandardebooks.org

A volunteer project that carefully typesets and formats public-domain books, free. Unlike Project Gutenberg the aim is quality over scale — each book is hand-finished with consistent typography.

Book · Open Source · Free
15
Unpaywallunpaywall.org

A tool and browser extension that finds legal open-access copies of paywalled papers. Unlike shadow libraries it searches only copies the author or publisher has released — entirely legal.

Academic · Reference · Open Source · Free
16
WikiTeamgithub.com

A toolset that downloads and archives MediaWiki wikis — 600,000+ preserved. Unlike general site copiers it is wiki-specific: it takes a full dump including page history and media, not just the HTML shell.

Archived · GitHub · Python · CLI
