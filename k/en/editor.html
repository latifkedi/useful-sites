Editors, IDEs & Terminals

The tools you spend most of the day inside: editors, IDEs and terminals. Choosing an editor is less a matter of taste than of workflow; picking one and truly learning its shortcuts pays more than switching often.

22 links

Apache NetBeans

netbeans.apache.org

A multi-language open-source IDE, strong for Java.

Open Source, Free

Awesome CLI

github.com

A list gathering useful, small command-line tools. Unlike broad lists such as awesome-shell, it focuses on small single-purpose tools you can install and use right away.

Awesome List, GitHub, CLI

Awesome Git Addons

github.com

A list of add-on commands and tools that enhance the git CLI. Unlike git clients, it collects not GUIs but tools that add new subcommands to `git`.

Awesome List, GitHub, Git, CLI

Awesome Hyper

github.com

A list of themes and plugins for Hyper, the web-tech terminal. Unlike native terminals such as Alacritty it is built on Electron, so themes and plugins are HTML/CSS/JS; the price is weight.

Awesome List, GitHub, CLI

Awesome Neovim

github.com

A list of plugins and configurations for the Neovim editor. Unlike Vim plugin lists, it gathers plugins written in Lua that rely on Neovim-only features such as Tree-sitter and LSP.

Awesome List, GitHub

Awesome VS Code

github.com

A list of extensions and resources for Visual Studio Code. Unlike the Marketplace itself it is curated: instead of thousands of extensions, it groups proven ones by language and task.

Awesome List, GitHub

Cmder

cmder.app

A portable, pleasant console package for Windows that ships with bash and unix commands. Unlike the built-in cmd it offers tabs, themes and unix tools together.

CLI, Open Source, Desktop

Eclipse Theia

theia-ide.org

An IDE framework that runs on the desktop and in the browser and takes VS Code extensions. The difference from VS Code is that it is a framework rather than a product — built for you to construct your own IDE on top of.

Open Source, Desktop, Server

Editor.md

pandao.github.io

An open-source, in-browser Markdown editor with live preview and export.

Open Source, In Browser

Embarcadero Dev-C++

sourceforge.net

A lightweight C/C++ IDE. Behind modern ones, yet it runs on weak hardware and remains the standard install in many Turkish university labs.

Free, Desktop, C Family, Networking

fli

github.com

Brings flight search to the command line, and because results are scriptable you can hang price tracking off a cron job.

Open Source, GitHub, CLI

hub

hub.github.com

A wrapper extending the git command line with GitHub operations (PRs, issues, forks).

CLI, Git, GitHub

Hyper

hyper.is

An open-source terminal built with web technologies and extensible via plugins.

CLI, Open Source, Desktop

Micro

micro-editor.github.io

A modern, intuitive terminal-based text editor with familiar shortcuts.

CLI, Open Source, Free

Neovim

neovim.io

A refactored Vim where configuration and plugins are written in Lua and language-server (LSP) support is built in. Unlike classic Vim, it has that Lua ecosystem and an asynchronous plugin architecture.

CLI, Open Source, Free

Notepad++

notepad-plus-plus.org

A lightweight source editor for Windows with syntax highlighting, multi-file search and replace, and macro recording. The reason to reach for it over VS Code is speed: it opens a huge log file in seconds without waiting on a language server.

Open Source, Desktop

ranwhen

github.com

A tool that visualises when your system was running, right in the terminal.

CLI, Open Source, GitHub

Sublime Text

sublimetext.com

A text/code editor focused on speed and fluidity, opening very fast.

Desktop, Paid

Visual Studio Code

code.visualstudio.com

The most widely used code editor: it starts light but approaches an IDE through language servers and debuggers. Unlike full IDEs such as JetBrains, every language comes as an extension — a small base with capability added on.

Open Source, Free, Desktop

VSCodium

vscodium.com

A community build of VS Code with Microsoft’s telemetry and branding stripped out. Same editor, same extension API; the difference is that the default marketplace is Open VSX rather than Microsoft’s, so some proprietary extensions are simply absent.

Open Source, Desktop

WakaTime

wakatime.com

Measures how long you spend in which project and language through an editor plugin. Against general time trackers it needs no manual start — the measurement comes from the editor itself.

Observability, Freemium, Plugin

Warp

warp.dev

A terminal written in Rust that keeps each command and its output as a separate block instead of one scrolling stream, so you can copy a single command’s output in one click. That block model and the built-in AI command suggestions are what set it apart.

Desktop, CLI, LLM
