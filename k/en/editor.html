Editors, IDEs & Terminals

The tools you spend most of the day inside: editors, IDEs and terminals. Choosing an editor is less a matter of taste than of workflow; picking one and truly learning its shortcuts pays more than switching often.

25 links

1
Apache NetBeansnetbeans.apache.org

A multi-language open-source IDE, strong for Java. Compared with IntelliJ IDEA it is entirely free and under Apache; in exchange its plugin ecosystem and smart completion are weaker.

Open Source · Free · Desktop · JVM (Java, Kotlin, Scala)
2
Awesome CLIgithub.com

A list gathering useful, small command-line tools. Unlike broad lists such as awesome-shell, it focuses on small single-purpose tools you can install and use right away.

Awesome List · GitHub · CLI
3
Awesome Git Addonsgithub.com

A list of add-on commands and tools that enhance the git CLI. Unlike git clients, it collects not GUIs but tools that add new subcommands to git.

Awesome List · GitHub · Git · CLI
4
Awesome Hypergithub.com

A list of themes and plugins for Hyper, the web-tech terminal. Unlike native terminals such as Alacritty it is built on Electron, so themes and plugins are HTML/CSS/JS; the price is weight.

Awesome List · GitHub · CLI
5
Awesome Neovimgithub.com

A list of plugins and configurations for the Neovim editor. Unlike Vim plugin lists, it gathers plugins written in Lua that rely on Neovim-only features such as Tree-sitter and LSP.

Awesome List · GitHub
6
Awesome VS Codegithub.com

A list of extensions and resources for Visual Studio Code. Unlike the Marketplace itself it is curated: instead of thousands of extensions, it groups proven ones by language and task.

Awesome List · GitHub
7
Cmdercmder.app

A portable, pleasant console package for Windows that ships with bash and unix commands. Unlike the built-in cmd it offers tabs, themes and unix tools together.

CLI · Open Source · Desktop
8
CodingFontcodingfont.com

Compares coding fonts two at a time in a tournament until one wins. Unlike a font list it turns browsing into a decision — it never puts twenty fonts side by side, only two.

Interactive · Free
9
Eclipse Theiatheia-ide.org

An IDE framework that runs on the desktop and in the browser and takes VS Code extensions. The difference from VS Code is that it is a framework rather than a product — built for you to construct your own IDE on top of.

Open Source · Desktop · Server
10
Editor.mdpandao.github.io

An open-source, in-browser Markdown editor with live preview and export. Unlike hosted note apps it is a component you embed in your own page, keeping the data yourself.

Open Source · In Browser · Free
11
Embarcadero Dev-C++sourceforge.net

A lightweight C/C++ IDE. Unlike modern IDEs it runs on weak hardware and remains the standard install in many Turkish university labs; in exchange its modern tooling support is thin.

Free · Desktop · C Family · Networking
12
fligithub.com

Brings flight search to the command line, usable as an MCP server, a CLI and a Python library. Unlike flight sites the results are scriptable, so you can hang price tracking off a cron job.

Open Source · GitHub · CLI
13
hubhub.github.com

A wrapper extending the git command line with GitHub operations (PRs, issues, forks). Unlike the official gh tool it wraps git commands directly; it now trails gh, which is preferred for new setups.

CLI · Git · GitHub
14
Hyperhyper.is

An open-source terminal built with web technologies and extensible via plugins. Unlike native terminals such as Alacritty it is built on Electron, so you theme it with HTML/CSS/JS at the cost of more weight.

CLI · Open Source · Desktop
15
Micromicro-editor.github.io

A modern, intuitive terminal-based text editor with familiar shortcuts. Unlike Vim and nano its learning curve is nearly flat: Ctrl+S saves, Ctrl+C copies — it works with desktop-editor habits.

CLI · Open Source · Free
16
Neovimneovim.io

A refactored Vim where configuration and plugins are written in Lua and language-server (LSP) support is built in. Unlike classic Vim, it has that Lua ecosystem and an asynchronous plugin architecture.

CLI · Open Source · Free
17
Notepad++notepad-plus-plus.org

A lightweight source editor for Windows with syntax highlighting, multi-file search and replace, and macro recording. Unlike VS Code its edge is speed: it opens a huge log file in seconds without waiting on a language server.

Open Source · Desktop · Free
18
Programming Fontsprogrammingfonts.org

A place to try monospaced coding fonts side by side on real code. Unlike a font download site, you see the ligatures and the 0/O and 1/l/I distinctions in the context that actually matters.

Reference · Free · In Browser
19
ranwhengithub.com

A tool that visualises when your system was running, right in the terminal; the repository has not been updated since 2013. Unlike plain last output it renders the data as a coloured time chart.

CLI · Open Source · GitHub
20
Sublime Textsublimetext.com

A text/code editor focused on speed and fluidity, opening very fast. Unlike VS Code it is native and opens instantly; in exchange its plugin ecosystem and built-ins are narrower, and it is paid.

Desktop · Paid
21
Visual Studio Codecode.visualstudio.com

The most widely used code editor: it starts light but approaches an IDE through language servers and debuggers. Unlike full IDEs such as JetBrains, every language comes as an extension — a small base with capability added on.

Open Source · Free · Desktop
22
VS Code Themesvscodethemes.com

A gallery previewing VS Code themes on real code. Against the marketplace you see a theme without installing it, and can compare how it looks across several languages at once.

Reference · Free · In Browser
23
VSCodiumvscodium.com

A community build of VS Code with Microsoft’s telemetry and branding stripped out. Same editor, same extension API; the difference is that the default marketplace is Open VSX rather than Microsoft’s, so some proprietary extensions are simply absent.

Open Source · Desktop · Free · Privacy
24
WakaTimewakatime.com

Measures how long you spend in which project and language through an editor plugin. Against general time trackers it needs no manual start — the measurement comes from the editor itself.

Observability · Freemium · Plugin
25
Warpwarp.dev

A terminal written in Rust that keeps each command and its output as a separate block instead of one scrolling stream, so you can copy a single command’s output in one click. That block model and the built-in AI command suggestions are what set it apart.

Desktop · CLI · LLM
